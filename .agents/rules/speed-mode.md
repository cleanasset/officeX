# Execution Standards

1. **Direct, Fast Edits**: Make targeted, single-step file edits without launching wasteful exploratory loops.
2. **Empirical Verification Required**: Always verify critical endpoints, imports, and database actions to prevent regressions. Show output directly to user.
3. **No Automated Browser Subagents**: Do not spawn browser subagents unless explicitly requested by the user.
4. **Git Push Reserved**: NEVER push to remote git; all commits and pushes are executed only by the user.
5. **Direct & Action-Oriented**: Deliver clear, actionable updates with concrete proof.
